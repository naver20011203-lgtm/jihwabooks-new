## 🚀 깃허브(GitHub) 업로드 및 GitHub Pages 배포 가이드

### 1단계: 깃허브 레포지토리에 파일 업로드
1. GitHub(또는 GitHub Desktop)에서 생성하신 레포지토리 폴더(예: `지화책방 이지은`)에 본 폴더(`지화책방 깃허브 종합`)의 **모든 파일과 폴더**를 그대로 복사하여 붙여넣습니다.
2. 커밋 메시지를 입력한 후 **Commit** 및 **Push**를 진행합니다.

### 2단계: GitHub Pages 무료 호스팅 활성화
1. GitHub 레포지토리 웹페이지 접속 ➔ 상단 메뉴의 **Settings** 클릭
2. 좌측 메뉴의 **Pages** 클릭
3. **Build and deployment** 항목의 **Source**를 `Deploy from a branch`로 선택
4. **Branch**를 `main`(또는 `master`) / `/ (root)`로 선택 후 **Save** 클릭
5. 약 1~2분 후 상단에 표시되는 무료 사이트 주소(`https://<아이디>.github.io/<레포지토리명>/`)로 전 세계 누구나 접속할 수 있습니다!

## 🎮 주요 인터랙션 및 조작법

- **마우스 좌클릭**: 다음 대사 / 다음 장면 진행, 양쪽 펼침면 책 다음 페이지 넘기기
- **마우스 우클릭**: 이전 대사 / 이전 장면으로 되돌아가기
- **책 읽기 모드 (2화 47번 장면)**:
  - 화면 우측 클릭: 다음 장 넘기기
  - 화면 좌측 클릭: 이전 장 넘기기 (앞표지에서 좌측 클릭 시 책방으로 복귀)
  - 하단 책척도 바: 마우스 클릭 및 드래그로 원하는 페이지 즉시 이동
- **음향 효과 (1화)**:
  - 대기화면(꽃 3송이)이 위로 올라감과 동시에 배경 빗소리 앰비언트가 재생되며 1~18번 장면 동안 매끄럽게 지속됩니다.
